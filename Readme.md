# Personal Introduction Program

## Project Overview

The Personal Introduction Program is a beginner-level Python project developed as part of Week 1: Python Basics.

The program asks the user for their name, age, city, and favorite hobby. It then displays a personalized welcome message.

## Objectives

- Understand basic Python programming.
- Learn how to use variables.
- Take user input using `input()`.
- Display information using `print()`.
- Practice f-strings and comments.

## Requirements

- Python 3
- A code editor such as Visual Studio Code or IDLE

## Installation and Setup

1. Install Python 3 from https://www.python.org/downloads/
2. During installation on Windows, select "Add Python to PATH" if the option is available.
3. Create a project folder named `week-1-python-basics`.
4. Create a file named `personal_intro.py`.
5. Copy the project code into the file.
6. Open a terminal in the project folder.
7. Run the following command:

```bash
python personal_intro.py
```

On some systems, use:

```bash
python3 personal_intro.py
```

## How It Works

1. The program displays a welcome heading.
2. It asks the user four questions.
3. The answers are stored in variables.
4. The program uses print statements and an f-string to display the information.
5. The user receives a friendly welcome message.

## Concepts Learned

- User input
- Output statements
- F-strings
